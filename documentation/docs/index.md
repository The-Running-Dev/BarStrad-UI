# BarStrad-UI 🍸✨

**A modern Angular-based bar menu application with multi-language support and interactive features**

[![CI](https://github.com/The-Running-Dev/BarStrad-UI/actions/workflows/ci.yml/badge.svg)](https://github.com/The-Running-Dev/BarStrad-UI/actions/workflows/ci.yml)
[![Release](https://github.com/The-Running-Dev/BarStrad-UI/actions/workflows/release.yml/badge.svg)](https://github.com/The-Running-Dev/BarStrad-UI/actions/workflows/release.yml)
[![Docker](https://img.shields.io/badge/docker-%230db7ed.svg?style=flat&logo=docker&logoColor=white)](https://github.com/The-Running-Dev/BarStrad-UI/pkgs/container/barstrad-ui)

BarStrad-UI is a modern Angular 19 application designed for restaurants and bars to provide an interactive digital menu experience. The application features multilingual support (Bulgarian and English), theme customization, table service integration, and real-time Discord notifications for orders.

## 🌟 Key Features

### � Modern Web Interface

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Progressive Web App**: Install as a native app on mobile devices
- **Angular Material**: Clean, modern UI components with consistent design
- **Theme Switching**: Light and dark theme options with user preference storage

### 🌍 Internationalization

- **Multilingual Support**: Built-in support for Bulgarian and English languages
- **Dynamic Translation**: Real-time language switching without page reload
- **Localized Content**: Menu categories, items, and UI elements fully translated
- **Flag Icons**: Visual language selection with country flags

### 🍽️ Menu Management

- **Interactive Menu Display**: Browse menu items organized by categories
- **Search Functionality**: Quick search across all menu items
- **Category Navigation**: Easy filtering by drink/food categories
- **Item Details**: Detailed information including prices and descriptions

### 🛒 Table Service & Orders

- **Table Integration**: Table number selection for order management
- **Order Processing**: Simple order placement with item selection
- **Discord Notifications**: Real-time order notifications sent to Discord webhooks
- **Order Confirmation**: User feedback with order status updates

### 🔧 Technical Features

- **Angular 19**: Latest Angular framework with modern features
- **TypeScript**: Full TypeScript implementation for type safety and developer experience
- **Angular Material**: Consistent UI components and design system
- **PWA Capabilities**: Progressive Web App features for mobile installation
- **Docker Support**: Containerized deployment with nginx serving
- **CI/CD Pipeline**: Automated testing, building, and deployment via GitHub Actions
- **Container Registry**: Automatic publishing to GitHub Container Registry for easy deployment

## 🐳 Docker Deployment

Deploy BarStrad-UI using Docker:

```bash
docker run -p 80:80 ghcr.io/the-running-dev/barstrad-ui:latest
```

Visit [http://localhost](http://localhost) to experience the application locally.
